# Mini Project 1

## Functions:

### > `bsc(bits, p, rng)`
Flips each bit in array `bits` with probability p, using seed provided by `rng`. Returns the new array.

### > `packet_errors(n_pkt, n_bits, p, rng)`
Returns the number of errors for each packet using `rng.binomial()`.

### > `attempts_until_clean(n_trials, q, rng)`
Returns the amount of attempts needed till a packet is cleaned, with `q` being the probability of it getting cleaned.

### > `tv_distance(pmf1, pmf2)`
Returns a calculation of the total variation distance between `pmf1` and `pmf2`.
